# 小红书标题生成器

## 什么时候用
用户要小红书标题、封面标题、爆款标题、标题改写时。

## 规则
1. 主标题必须包含：具体实体名、一个数字、一个悬念缺口。
2. 备选里疑问句和陈述句混搭，至少 2 条口语开头。
3. 禁止空心大词（赋能、抓手、闭环、颠覆）。
4. 每条不超过 20 字，手机上不折行。

## 输出格式
主标题：xxx
备选 1-5：xxx
