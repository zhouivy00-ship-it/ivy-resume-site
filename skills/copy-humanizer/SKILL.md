# 文案去 AI 味

## 什么时候用
一段文案读起来像议论文、像通稿、像 AI 写的时候。

## 检测清单
- 「不仅…更…」类排比
- 破折号滥用
- 空心大词：赋能 / 抓手 / 闭环 / 颠覆 / 重塑
- 万能开场：在…的今天 / 随着…的发展
- 废话连接词：值得注意的是 / 需要指出的是

## 改写原则
1. 先说结论，再补理由。
2. 形容词换成具体动作或数字。
3. 长句拆短，允许口语和不完整句。
4. 保留作者原本的语气，不要变成另一个人。
